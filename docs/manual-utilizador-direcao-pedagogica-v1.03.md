## 1. Introdução

### Objetivo do manual

Este manual descreve, de forma passo a passo, como a **Direcção Pedagógica** utiliza a plataforma **FOCO**: aceder ao sistema, gerir cursos e formadores, acompanhar turmas, validar horários, gerir módulos, planos de execução e configurações (geral, delegações e utilizadores).

### Público-alvo

Este documento destina-se aos utilizadores com a função **Direcção Pedagógica** no Instituto Foco, responsáveis pela supervisão pedagógica, validação de horários, gestão académica dos cursos e administração das áreas permitidas em Configurações.

### Requisitos para utilização

- Ligação à Internet activa.
- Navegador web actualizado (Google Chrome, Microsoft Edge ou equivalente).
- Conta activa na plataforma FOCO com o perfil **Direcção Pedagógica**.
- Acesso à caixa de correio electrónico associada à conta (para recuperação de palavra-passe).

### Permissões do perfil Direcção Pedagógica

A função Direcção Pedagógica recebe um conjunto completo de permissões académicas e de configuração (**excepto Perfis**). O menu lateral mostra apenas as opções para as quais o utilizador tem permissão.

| Área | Acesso |
|------|--------|
| Painel | Ver e consultar |
| Cursos | Ver, criar, editar, eliminar |
| Módulos | Ver, criar, editar, eliminar |
| Formadores | Ver, criar, editar, eliminar |
| Turmas / Horários | Ver, criar, editar, validar |
| Planos de execução | Ver, criar, editar |
| Configurações → Geral | Ver e editar |
| Configurações → Delegações | Ver, criar, editar |
| Configurações → Utilizadores | Ver, criar, editar |
| Configurações → **Perfis** | **Sem acesso** |

> **Nota:** A gestão de Perfis está reservada a perfis administrativos superiores. A Direcção Pedagógica **não** vê a aba Perfis.

## 3. Recuperar Palavra-passe

Caso o utilizador não se recorde da palavra-passe, a plataforma FOCO disponibiliza um processo de recuperação em **três etapas** (**1 — 2 — 3**).

### 3.1 Solicitar a recuperação

#### Objetivo

Iniciar o processo de recuperação de palavra-passe a partir do ecrã de login.

#### Passos

1. No ecrã de login, clicar em **“Esqueceu a palavra-passe?”**.
2. O sistema apresenta o formulário na etapa 1 de 3.
3. Introduzir o email da conta e confirmar o envio.

## 15. Boas Práticas e Resolução de Problemas

### Boas práticas

1. Validar horários apenas após verificar conflitos de formador e sala.
2. Manter módulos e cursos actualizados antes de abrir novas turmas.
3. Preferir **desactivar** registos em vez de eliminar, quando existirem históricos.
4. Usar filtros de período no Painel no início de cada dia de trabalho.
5. Não partilhar credenciais.

### Problemas frequentes

| Problema | O que fazer |
|----------|-------------|
| Não consigo entrar | Verificar credenciais; usar recuperação OTP |
| Não vejo a aba Perfis | Comportamento esperado neste perfil |
| Horário não valida | Resolver conflitos e voltar a tentar |
| Lista vazia no Painel | Confirmar filtro de ano/ingresso e Actualizar |
| Não consigo eliminar curso/módulo | Verificar dependências |
| Email OTP não chega | Verificar spam; repetir pedido |

## 16. Glossário

| Termo | Significado |
|-------|-------------|
| **FOCO** | Plataforma de gestão académica do Instituto Foco |
| **Direcção Pedagógica** | Perfil com supervisão académica e validação de horários |
| **Curso** | Oferta formativa registada na plataforma |
| **Módulo** | Unidade formativa da biblioteca académica |
| **Formador** | Docente / trainer atribuível a horários |
| **Turma** | Grupo de formandos num curso/período |
| **Horário** | Alocação de módulo + formador + tempo (+ sala) |
| **Validação** | Aprovação pedagógica de um horário proposto |
| **Plano de execução** | Sequência e carga de módulos de um curso |
| **Delegação** | Unidade / polo associado à instituição |
| **OTP** | Código de verificação de utilização única |
| **Perfis** | Funções e permissões (**fora do âmbito deste perfil**) |
